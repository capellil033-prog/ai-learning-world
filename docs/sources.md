# Herkunft und fachliche Quellen

- Modelle, Fahrsteuerung, Parklogik, Kamera, Schnee und Designsystem: vom Nutzer bereitgestellter Token Transit. Prüfsummen: `template-hashes.json`. Die Vorlage bleibt unverändert.
- MCP-Rollen: [offizielle Architektur](https://modelcontextprotocol.io/docs/learn/architecture).
- Tools, Resources, Prompts: [offizielle Server-Konzepte](https://modelcontextprotocol.io/docs/learn/server-concepts).
- Agenten und beobachtungsabhängige Schleifen: [Anthropic, Building effective agents](https://www.anthropic.com/research/building-effective-agents).

Die App ist eine didaktische Simulation. Sie führt keine echten Modell-, Wetter- oder MCP-Aufrufe aus. Tokenzerlegung und Datensätze sind als illustrative Beispiele gekennzeichnet.
